## About

**LUT Studio** is a standalone web application developed by **GLX** to create, preview, import and export LUTs directly in a browser.

Loaded images and LUTs remain on the device. No account, server or upload is required.

---

## Features

### Import

- JPG, PNG and WebP images
- CUBE, TIFF and PNG LUTs
- Drag-and-drop or file selection
- Fully local processing

### Color grading

- Exposure, contrast, highlights and shadows
- Temperature, tint, saturation and vibrance
- Lift, gamma and gain
- Eight quick looks: Neutral, Warm Cinema, Blue Night, Pastel, Teal & Orange, Dense B&W, Chrome and Soft Film

### Preview

- Adjustable before/after comparison
- Original or graded result views
- RGB histogram
- Built-in color reference image
- French and English interface

### Export

- 1024 × 1024, 16-bit RGB TIFF LUT with Deflate compression
- 17³, 33³ or 65³ CUBE LUT
- PNG preview of the graded image

## Use locally

1. Download the [project archive](https://github.com/GaLeX-Le-Penguin/LUT-Studio/archive/refs/heads/main.zip)
2. Extract the archive completely
3. Open `index.html` in a modern browser

No installation or executable is required.

```text
LUT-Studio/
├── index.html
├── README.md
├── README_EN.md
└── LICENSE
```

---

## Privacy

Images and LUTs are processed in browser memory. LUT Studio does not transmit them to a remote service.
